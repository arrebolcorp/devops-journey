1. What an OS does.
An OS is a operating system that to install in the hardware or virtual hardware (could be a personal computer or in the cloud) the three most popular OS are Windows, MAC OS and Linux, those OS could be used for different things and environments and some people prefer one more other, but the main function is have a interface where we have a possibilities for install programs, software, administrating files, code etc.
2. 8 glossary terms in your own words.
Operating system: Is the interface for managing, administrating a installing software and files. Do not necessary have a physical hardware for install a OS.
Kernel: is the core program of an OS that acts as the critical bridge between software applications and computer hardware.
Shell / terminal: Is the application to writing commands for creating, consulting, deleting etc.
Hypervisor: Is the most important part in the fundamentals functions in Virtualization because is a technology that allows hosting multiple virtual computer on a physical computer.
Host / Guest: The host is where hosting my... for example; my OS, my server, my VM.
Virtual machine: Is a technical concept for explain how I can duplicate my hardwere whithout have another physical cumputer.
ISO image: Is the format where packaged the OS.
Snapshot: is the instant image to facility to create a VSI maybe as a copy of security, duplicate a virtual environment. Etc.
3. A Type 1 vs Type 2 comparison.
  The Hypervisor type 1 is used for big companies that have a bare metal (Physical server) while Type 2 is more a low dimensity using a personal computer. Also the type 1 install the Hypervisor directly into the bare metal.
