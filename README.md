# DevOps Journey — 26 Weeks

A hands-on learning repository documenting my path to mastering DevOps, Linux, networking, containers, and cloud infrastructure from scratch.

## Weekly Index

### [Week 01: Linux Fundamentals](semana-01-linux/)

During this first week, I learned how to set up an Ubuntu virtual machine, navigate the Linux file system using relative and absolute paths, and edit configuration files safely with Vim. I also practiced managing software packages with `apt` and `dpkg`, reading system logs, and monitoring hardware resources from the terminal.
