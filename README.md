# DevOps Journey — 26 Weeks

A hands-on learning repository where I document my practice in DevOps,
Linux, networking, containers and cloud infrastructure, starting from scratch.

## Weekly Index

### [Week 01: Linux Fundamentals](semana-01-linux/)

During the first week I set up an Ubuntu virtual machine, learned to navigate
the Linux file system with absolute and relative paths, and practiced editing
copies of configuration files with Vim. I also practiced managing software
with `apt` and `dpkg`, reading system logs, and monitoring resources from the
terminal.
